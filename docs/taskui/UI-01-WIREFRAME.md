# UI-01 · 工作区线框（设计提案，非运行截图）
基于 TaskUI **对象管理型**主模式 + **引导向导型**辅助模式。无新增主导航页、永久诊断侧栏或首屏图表。

## S-desktop · Windows Qt6 主界面（目标）
```text
┌──────────────────────────── IDM Next ─────────────────────────────┐
│ 文件 任务 视图 帮助           [新建 Ctrl+N] [更多]               │
├──────────────┬───────────────────────────────────────────────────┤
│ 全部下载     │ 文件名       大小      状态/进度       速度      │
│ 未完成       │ ──────────────────────────────────────────────── │
│ 已完成       │ ubuntu.iso   5.2 GB    下载中 72%     12 MB/s    │
│ 失败         │ app.zip      80 MB     已暂停           —        │
│ 队列 / 类型  │                                                   │
│ (可收折)     │ 任务表：主要工作区，右键对象操作；双击任务详情   │
├──────────────┴───────────────────────────────────────────────────┤
│ 任务数 / 速度                                      流量模式     │
└──────────────────────────────────────────────────────────────────┘
```
详情：维持现有对话框（或后续经验证改为可关详情面板），展示任务 URL、错误、文件及校验。禁止在 UI-01 假定已改造。

## S-popup · 浏览器扩展资源发现（目标 400×560）
```text
┌────────────────────── IDM Next ● 已连接 ── ⚙ ┐
│ 当前标签页域名                                │
│ [搜索资源……………………]  类型: 全部 视频 音频 文件 │
├───────────────────────────────────────────────┤
│ □ 资源名称.mp4       MP4 · 体积      [下载]     │
│ □ 文件 archive.zip   ZIP · 体积      [下载]     │
│         滚动资源列表（主要工作区）             │
│                无资源 → 下一步建议             │
│                连接异常 → 可点诊断             │
├───────────────────────────────────────────────┤
│ 已选 N 项                          队列 下载 │
└───────────────────────────────────────────────┘
```
- 浏览器下载候选与“最近转交”保留，但属于 **按需次区域**；当两个次区域均有内容时不得挤掉资源核心列表。具体折叠方式由 G3 测试决定，不预先设计固定复杂卡片。
- 待确认请求必须呈现 **未知**，不得直接显示“下载成功”，不得一键自动重发。
- 批量失败或部分成功时，从操作条出现**结果摘要**（例如“已接收2/3；未知具体条目”），不把无身份的总数映射到资源行，保留原选择状态以便核查；默认不显示为一个永久占地卡片。

## S-diagnostics · Popup 内逐步排错（G2 目标，当前不存在）
```text
┌──────────── 桌面端未连接 ──────── × ┐
│ 1 检查客户端是否运行    [重新检测] │
│ 2 检查 Native Host 注册 [查看步骤] │
│ 3 检查扩展与程序版本     [复制诊断] │
│ ───────────────────────────────── │
│ 仅展示已验证结果；未知要写“未知”。 │
│ [返回资源]              [打开帮助] │
└───────────────────────────────────┘
```
- 默认**只读排查**，绝不静默执行脚本、更改注册表、取消下载、清理 UUID。
- G2 提供清晰返回路径、键盘焦点和恢复状态。
- 以上仅为 G1 设计目标，真实空间比率、Tab/键盘、截图证据留待 G3。
